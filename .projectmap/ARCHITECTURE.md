## Overview
`lecturevideo` is a self-contained Claude Code **agent skill** that turns a topic into a
complete teaching video. The pipeline runs in four phases: outline → marp slides
(HTML/PDF/per-page PNG) → per-page SRT narration written by parallel sub-agents → an
auto-playing HTML video player. The architecture splits LLM work from deterministic work:
`SKILL.md` orchestrates the phases and dispatches narration sub-agents, while small
stdlib-only Python scripts (plus a marp-cli shell wrapper) do the reproducible,
token-cheap transforms, and a dependency-free JS player renders the result in the browser.
Everything runs locally — no external plugins or services.

## Entry points
- `SKILL.md` — the actual skill entry point; defines the phases and orchestrates everything below.
- `scripts/compile_marp.sh` — `slides.md` → `slides.html` + `slides.pdf` + per-page PNGs (wraps marp-cli).
- `scripts/check_fit.py` — `slides.html` → overflow report (headless Chrome); exit `3` if any page's content runs past the slide box. Run after compile_marp.
- `scripts/split_slides.py` — `slides.md` → `.slides.json` (pages + overlays + mathwrites).
- `scripts/render_mathwrite.py` — mathwrite TeX segments → `.mathwrite.json` (MathJax SVGs + on-slide bboxes via headless Chrome); only needed when the deck declares mathwrite blocks.
- `scripts/plan_subagent_batches.py` — `.slides.json` → narration batch plan (stdout JSON).
- `scripts/derive_timeline.py` — per-page SRTs + `.slides.json` → global `timeline.json` (silent path).
- `scripts/synthesize_tts.py` — voiced path: IndexTTS-2 narration → `narration.wav` + audio-accurate `timeline.json` (replaces derive_timeline).
- `scripts/build_video.py` — `timeline.json` + slide PNGs (+ `narration.wav`) → playable `video/index.html`.

## Build / test
No automated test suite. The scripts are stdlib-only Python (≥ 3.8, no `pip install`);
the player is static JS/CSS/HTML. End-to-end a topic produces `output/<slug>/` (see README
"輸出結構"); the manual pipeline per topic is: `compile_marp.sh` → `split_slides.py` →
`plan_subagent_batches.py` → (sub-agents write SRTs) → `derive_timeline.py` →
`build_video.py`, then open `output/<slug>/video/index.html` in a browser. Requires
`node`/`npx` (for `@marp-team/marp-cli`), `python3`, and any modern browser.

## Conventions
- **Deterministic vs LLM split:** anything reproducible lives in `scripts/` (Python/shell);
  only the writing (outline, slides, narration) is done by the LLM/sub-agents. Keep new
  mechanical work in scripts to save tokens.
- **Script shape:** each Python tool is a `main(argv) -> int` CLI with exit codes
  `2` = usage error, `1` = runtime error, `0` = ok; progress prints `[<name>] …` to stdout,
  warnings/errors go to stderr.
- **Overlay markers flow:** marp markdown uses `<!-- overlay-begin: id=…, label="…" -->` /
  `<!-- overlay-end: id=… -->`; narration SRT uses `[overlay:id]` … `[/overlay:id]`. These
  propagate md → `.slides.json` → `timeline.json` → faded badges in the player.
  The same SRT cues (markers stripped, original text kept) also become `timeline.captions[]`,
  which the player shows as a synced subtitle bar (`CC` button / `c` key).
- **Mathwrite (hand-written math)** rides the same contract with marker ids `<id>.<seg>`:
  `mathwrite-begin/seg/end` comments + a `<div class="mathwrite">` in slides.md; the PNG
  render blanks the div and the player stroke-draws the MathJax SVGs into that region in
  sync with narration (see CLAUDE.md "Mathwrite").
- **Timing:** each per-page SRT starts at `00:00:00,000`; global times are derived by
  concatenating page durations (default 20s when a page's SRT is missing/empty).
- **Artifacts:** JSON is the interchange format; dotfiles (`.slides.json`, `.state.json`)
  are internal/resumable state. `build_video.py` injects the timeline into
  `assets/player/index.html` via the `/* __TIMELINE__ */` placeholder and symlinks slide PNGs.
